# Simple Quiz Management System

A web-based system for managing quizzes and assessments. There are three types of users: Admin, Professor, and Student. Each user type has specific roles and responsibilities:

- **Admin** can manage users, departments, reports, and sections.
- **Professor** can manage assessments and view results.
- **Student** can take assessments and view their results.

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- PHP, MySQL
- XAMPP (for local server)
- Some external libraries for enhanced UI/UX
